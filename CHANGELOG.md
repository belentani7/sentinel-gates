# Changelog

Este proyecto sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y [Semantic Versioning](https://semver.org/lang/es/).

## [0.1.0] - 2026-08-22

### Added

Se crea la base de Sentinel Gates con un modelo TypeScript de evaluación de quality gates, logs JSON con `requestId`, tipado estricto, Biome, Vitest con umbrales de cobertura, Stryker, revisión de fronteras arquitectónicas y un workflow SEDA/CSG. Se incluyen CodeQL, auditoría de dependencias, escaneo de secretos, plantillas de issue y pull request, documentación de arquitectura y un ADR fundacional.
